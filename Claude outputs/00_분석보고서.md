# 실제 관측 데이터 기반 해저 확장 중심부(대서양 중앙해령) 분석 보고서

**과제연구 주제**: 해저확장과 판구조론 — 음향수심법(echo sounding)을 이용한 실제 수심 데이터 분석
**기존 자료**: `simulation.py` (순수 수식으로 만든 가상 지형 3D 시각화)
**이번 작업**: 위 스크립트와 같은 좌표대(대서양 중앙해령 북부, 위도 20°~30°)에 대해 **실제
전지구 수심 관측 자료**를 조회·분석하고("이게 중앙해령이 맞느냐"는 검증을 거쳐 경도 범위를
-45°~-35°에서 -51°~-35°로 확장), 여기에 **지자기 이상(고지자기) 자료**까지 더해 가상
시뮬레이션을 실제 데이터 기반 연구로 전환하는 것

---

## 1. 왜 기존 스크립트로는 부족했는가

`simulation.py`의 주석에는 "실제 지구물리학 데이터 기반"이라고 적혀 있지만, 실제 내용은

```python
ridge_shaping = 2600 * np.exp(-((X + 40) / 2.2)**2)
rift_valley_shaping = -750 * np.exp(-((X + 40) / 0.35)**2)
geological_texture = 180*np.sin(...)*np.cos(...) + 90*np.sin(...)*np.sin(...) + 난수
```

와 같이 지수함수·삼각함수·난수를 조합해 "그럴듯해 보이는" 지형을 수작업으로 만든 것으로,
실제 관측값은 전혀 들어있지 않다. 과제연구에서 "음향수심법 바탕"이라고 쓰려면 실제 음향측심
기록이 반영된 데이터를 사용해야 하므로, 이번 분석에서는 이를 실제 데이터로 교체했다.

## 2. 데이터 출처 (음향수심법과의 연결)

| 항목 | 내용 |
|---|---|
| 데이터셋 | NOAA NCEI **ETOPO 2022** 15 Arc-Second Global Relief Model (`bed_elev` 레이어) |
| 제공 방식 | NOAA ArcGIS ImageServer `identify` API (지점별 실시간 조회, 기준면: 평균 해수면) |
| 서비스 주소 | `https://gis.ngdc.noaa.gov/arcgis/rest/services/DEM_mosaics/DEM_all/ImageServer` |
| 음향수심법과의 관계 | ETOPO는 전 세계 연구선·상선이 **음향측심기(에코사운더)**로 실측한 수백만 건의 수심 기록(NOAA NCEI trackline geophysical database)에 위성 고도계 기반 중력 반전 수심 자료를 결합해 만든 합성 지형 모델이다. 즉 격자값 하나하나는 실제 음파 왕복시간(t)과 해수 중 음속(v≈1500 m/s)으로부터 `수심 = v·t / 2` 원리로 계산된 실측치(또는 그 보완 자료)에 뿌리를 두고 있다. |

**한계**: 이번 실행 환경의 네트워크 제약으로 200×200 같은 고해상도 격자 전체를 통째로
내려받을 수는 없었고, API에 지점 좌표를 하나씩 질의하는 방식으로 격자를 채웠다. 이는 실제
해양탐사선이 성긴 항적을 따라 음향측심을 하고, 그 사이는 보간(interpolation)으로 채워
지형도를 완성하던 고전적 방법 — Marie Tharp와 Bruce Heezen이 1950~60년대에 R/V *Vema*,
*Atlantis*호의 실측 수심선을 보간해 대서양 중앙해령과 열곡을 처음 지도화한 방식 — 과
원리적으로 동일하다. 격자 사이는 3차 보간(cubic interpolation)으로 채웠으며, 시각화에서는
실측점(빨간 점)과 보간면을 항상 구분해서 표시했다.

조사 범위도 처음에는 기존 `simulation.py`와 동일하게 경도 -45°~-35°로 잡았으나, 능선이
서쪽 경계에 걸려 있어 "이게 정말 중앙해령이 맞느냐"는 의문이 제기되었다. 이에 서쪽으로
6° 넓혀 **경도 -51°~-35°, 위도 20°~30°**로 확장했고, 그 결과는 3.2절에서 다룬다.

**격자 밀도 보완(2단계)**: 처음에는 8(경도)×6(위도) = 48개 지점 + 26°N 단면 16개 = 총
53개 지점으로만 조회했는데, 3D로 렌더링해 보니 위도 26°~28° 사이에서 실제로는 존재하지
않는 "쌍봉(saddle) 모양"의 보간 아티팩트가 나타났다. 격자가 너무 성겨 큐빅 보간이 두
위도 사이를 과도하게 휘어 이은 것이었다. 1차로 경도 1°×위도 1° 간격 153개 지점으로
보완했고, 이후 "더 정확한 데이터"를 위해 경도·위도 모두 **0.5° 간격**까지 조밀화해
**총 533개 지점**(경도 33개×위도 21개 정규 격자)으로 최종 재조사했다. 그 결과는
3.2·3.3절에서 다룬다.

### 3.2 "이게 중앙해령이 맞나요?" — 조사 범위를 넓혀 확인

처음 범위(-45°~-35°)에서는 위도 20~24°N 구간의 최천부가 서쪽 경계(-45°)에 걸려 있어,
능선의 동쪽 사면만 보고 서쪽은 못 본 것이 아니냐는 의문이 자연스럽게 들 수 있었다.
그래서 서쪽으로 6°(-51°까지) 넓혀 다시 조회했다. 26°N 단면 기준으로 정리하면:

| 구간 | 수심 경향 |
|---|---|
| -50°~-46° (서쪽 심해저 방향) | -4900 ~ -4000 m, 능선에서 멀어질수록 대체로 깊어짐 |
| -45°~-41° (능선/축 구간) | -3350 ~ -3990 m, 가장 얕은 융기부 |
| -40°~-35° (동쪽 심해저평원) | -5050 ~ -5880 m, 뚜렷하게 깊어짐 |

즉 **서쪽 사면 → 능선(축) → 동쪽 사면**의 완전한 단면 구조가 드러났다(그림
`04_transect_profile_26N.png` 참고). 20~24°N 구간도 -51°, -48° 지점이 -45°보다
더 깊게 나와, -45°가 화산체 가장자리가 아니라 실제 국지적 융기(능선)임이 재확인됐다.
따라서 이 데이터는 대서양 중앙해령을 실제로 담고 있다고 판단할 수 있으며, 위치도
실제 TAG(Trans-Atlantic Geotraverse) 열수구 구역(26°08′N, 44°49′W)과 거의 일치한다.

위도가 높아질수록 능선 정상 위치가 대체로 **서쪽(-46°)→중앙(-44°)→동쪽(-43°)**으로
계단식 이동하는 경향이 보이며, 이는 실제 대서양 중앙해령이 여러 변환단열대(Kane,
Atlantis 단열대 등)에 의해 몇 도 단위로 어긋나 있는 것과 같은 성격이다. 최초 53개
지점, 1차 보완 153개 지점, 최종 533개 지점으로 갈수록 이 계단 이동이 점점 더 매끄럽게
드러났다 — 격자가 성길수록 실제로는 없는 굴곡(쌍봉 아티팩트)이 생기고, 조밀할수록
보간이 실제 지형에 수렴한다는 것을 이번 재조사 과정 자체가 보여준다.

### 3.4 26°N 단면(가상의 음향수심 항적) 분석

26°N을 가로지르는 실측 단면은 다음과 같은 형태를 보였다.

- 경도 -44°에서 수심 **-3353.9 m**로 가장 얕아짐 (해령 정상부)
- 정상부 바로 동쪽(-43°)에서 수심이 -3992.9 m로 약 640 m 급격히 깊어짐 → **V자 열곡(rift valley)** 존재를 시사
- 서쪽으로는 -46°~-50°에서 -4000~-4900 m로, 동쪽으로는 -40°~-35°에서 -5050~-5880 m
  심해저 평원으로 각각 깊어짐 → 능선을 사이에 둔 좌우 사면 구조 확인

흥미롭게도 이 결과는 실제 학계에 보고된 **TAG(Trans-Atlantic Geotraverse) 열수구 구역**
(26°08′N, 44°49′W)의 위치·수심(정상부 약 -3000~-3700 m)과 거의 일치한다. 이는 이번에
API로 조회한 값이 실제 지형을 신뢰할 수 있는 수준으로 반영하고 있음을 보여주는 교차 검증
근거로 볼 수 있다.

### 3.4-B 음향수심법 원리 직접 계산 — "이 데이터가 정말 음향수심법과 관련 있나?"

지금까지의 3D 지형·단면·등수심선도는 모두 **음향수심법으로 만들어진 결과물**(ETOPO 2022
격자)을 다룬 것이었지, 음향수심법 자체의 계산 원리가 화면에 직접 드러난 적은 없었다.
이를 명시적으로 보여주기 위해, 26°N 단면의 실측 수심값을 거꾸로 "이 수심을 측정하려면
음파가 몇 초 만에 왕복했어야 하는가"로 환산했다.

공식: 수심 `d = v · t / 2` (v = 해수 중 평균 음속, t = 음파의 왕복 시간) 이므로,
`t = 2d / v` 로 역산할 수 있다. 여기서는 v ≈ 1500 m/s(원양 심층수의 평균적인 음속 근사치)
를 가정했다 — 실제 음속은 수온·염분·수압에 따라 약 1450~1540 m/s 사이에서 달라지므로,
실제 음향측심기는 현장에서 측정한 음속 프로파일(sound velocity profile)로 이 값을
보정한다는 점도 함께 밝혀 둔다.

**계산 예시** (해령 정상부, 경도 -44°): 실측 수심 3353.9 m →
`t = 2 × 3353.9 m ÷ 1500 m/s ≈ 4.47초`. 즉 배에서 쏜 음파가 해저에 반사되어 되돌아오기까지
약 4.47초가 걸렸을 때 측정되는 수심이 바로 이 값이라는 뜻이다. 26°N 단면의 16개 실측점
전체에 대해 같은 계산을 반복하면 모든 점이 `d = v·t/2` 직선 위에 정확히 놓인다(그림
`07_echo_sounding_principle.png`) — ETOPO 격자의 수치 하나하나가 실제로는 이런 왕복시간
측정값(또는 그것과 동등한 위성 중력 보정치)이라는 것을 계산으로 확인한 것이다. 전체
왕복시간 표는 `output/echo_sounding_travel_time_26N.csv`에 저장했다.

### 3.5 실제 데이터 vs 기존 순수 수식 시뮬레이션 비교

`output/02_real_vs_synthetic_comparison.html` 에서 두 지형을 나란히 비교할 수 있다.

- 기존 시뮬레이션: 좌우대칭에 가까운 매끈한 하나의 능선 + 인공적으로 삽입한 열곡 → "이상화된
  교과서적 형태"
- 실제 데이터: 위도에 따라 능선의 높이·위치·폭이 불규칙하게 변하고, 국지적으로 해산(seamount)
  으로 보이는 고립된 융기부(28~30°N, -44°~-45° 부근)가 존재하는 등 훨씬 복잡하고 비대칭적인
  지형 → "실제 지구의 지질학적 복잡성"

**[규모·위치 재조정 안내]** 원본 `simulation.py`는 융기 2600m·열곡 750m, 능선 중심 경도
-40°로 설정되어 있었다. 이는 실측한 실제 relief 규모(약 3300m)보다 과장되어 있었고
(3D로 렌더링하면 Earth 컬러스케일에서 정상부가 육상 색(흰색)에 가깝게 부풀어 "매끈한 감자"
처럼 보이는 문제가 있었다), 능선 위치도 실측으로 확인된 실제 축 위치(-44°, TAG 구역과 일치)와
어긋나 있었다. 이에 융기 1800m·열곡 450m·중심 -44°로 재조정했다. `analysis.py`와 3D 뷰어의
"가상 시뮬레이션(재조정판)" 탭에는 이 값이 반영되어 있다.

### 3.6 26°N 지자기 이상(고지자기, EMAG2v3) 단면

해저 확장의 또 다른 핵심 증거인 대칭적 자기 줄무늬(Vine–Matthews–Morley 가설)를 확인하기
위해 NOAA **EMAG2v3**(Earth Magnetic Anomaly Grid) 자료를 같은 26°N 단면을 따라
조회했다(광역 1° 간격 16개 지점 + 축 인근 고해상도 0.25° 간격 17개 지점). 아래
`04_transect_and_magnetic_26N.png`에서는 이 지자기 이상 단면을 음향수심 프로파일·경사
그래프와 **같은 경도(x축)를 공유하는 누적(stacked) 패널**로 겹쳐 그렸다 — 실제 해양지구물리
조사 보고서에서 수심-중력-지자기 프로파일을 이런 식으로 같은 축 아래 나란히 쌓아 대응
관계를 보여주는 관례를 따른 것이다. 3D 뷰어에서도 같은 방식으로 두 그래프를 하나의 패널에
통합했다.

| 구간 | 진폭 범위 |
|---|---|
| 광역(1° 간격, -50°~-35°) | -32.4 ~ 76.4 nT |
| 축 인근 고해상도(0.25° 간격, -46°~-42°) | -34.7 ~ 65.1 nT |

결과는 솔직히 말해 교과서에 나오는 것처럼 깔끔한 대칭 줄무늬로 보이지는 않았다.
이론적으로 기대되는 해저 확장 자기 이상은 수백 nT급 진폭으로 축을 중심으로 대칭
반전되는데, 실측값은 진폭이 수십 nT 수준으로 작고 불규칙하게 진동한다. 이는 EMAG2v3가
여러 시기·여러 기종의 조사 자료를 압축한 2 arc-분(약 3.7km) 해상도의 전지구 격자이기
때문으로 해석된다 — 실제 축 부근의 좁은 자기 줄무늬(폭 수~수십 km)를 해상하려면 선박
자력계로 직접 측선을 따라 측정한 고해상도 원자료가 필요하다. **이 한계 자체가 "실제
데이터는 교과서 그림처럼 깔끔하지 않다"는 이번 과제연구 전체의 핵심 교훈과 일치하므로
숨기지 않고 그대로 분석·보고했다.**

**[지자기 격자 확장 및 3D 색상 매핑]** 위 26°N 단면 하나만으로는 자기 이상의 공간적
패턴을 보기 어려워, 위도 20·22·24·26·28·30°N(2° 간격) x 경도 -50°~-35°(1° 간격) =
96개 지점으로 지자기 이상 조회 범위를 넓혔다(`data/magnetic_anomaly_grid.csv`). 이
값을 3D 지형면과 같은 150x150 격자로 보간한 뒤, **지형면의 굴곡(고도)은 그대로 두고
표면의 "색"만 수심 대신 지자기 이상값(RdBu 발산 색상표)으로 바꿔 칠하는 토글 버튼**을
`01_real_data_3d_surface.html`에 추가했다. 같은 3차원 지형을 "높낮이"라는 렌즈와
"지자기 이상"이라는 렌즈로 각각 돌려 보며 비교할 수 있다. 다만 96개 지점(위도 2°·경도
1° 간격 ≈ 100km 이상 격자)은 3.6절에서 이미 확인한 EMAG2v3 자체의 한계(수 km급 줄무늬를
해상하기엔 원자료 해상도가 부족함)에 더해 격자 자체도 성기므로, 이 3D 색상 지도는
"교과서적으로 깔끔한 줄무늬"가 아니라 "실제로 조회한 지자기 이상의 광역적 분포"를
보여주는 용도로 해석해야 한다.

### 3.7 "해령이면 가운데가 파여 있어야 하는 것 아닌가?" — 열곡(rift valley) 미표현 원인 검증

3D 지형면을 보면 능선(해령 축)이 완만하게 솟아 있을 뿐, 실제 대서양 중앙해령의 특징인
좁고 깊은 중앙 열곡(axial rift valley)이 뚜렷이 파여 있지는 않다. 이 의문에 답하기
위해 26°N, -45.5°~-43.5°W 구간을 기존 0.5° 간격(약 50km)보다 훨씬 촘촘한 **0.02~0.1°
간격(약 2~11km)**으로 재조회했다(`data/rift_valley_fine_scan_26N.csv`, 43개 지점).

결과는 아래 `08_rift_valley_resolution.png`에 나타난 것처럼, 실제로는 단 **21.9km**
거리 안에서 수심이 **-2570m(고점, -44.70°W) ↔ -4380m(저점, -44.92°W)** 로 약
**1810m나 급격히 오르내리는 거친 단층 지형**이 존재했다. 이는 열곡벽·열곡저에
해당하는 실제 요철로 볼 수 있다. 그런데 3D 지형면은 0.5° 간격(약 50km) 격자점만을
큐빅 보간으로 이어 만든 것이기 때문에, 이 그래프의 굵은 빨간 선(0.5° 격자)처럼 완만한
곡선이 되어버린다 — 2~11km 규모의 좁은 요철은 50km 간격 격자점 사이에서 수학적으로
평균화되어 사라지는 것이다.

**결론: "열곡이 없다"가 아니라 "3D 지형면 제작에 쓴 격자 해상도(0.5°, 약 50km)가
실제 열곡의 폭(수~수십 km)보다 훨씬 성기기 때문에, 보간 과정에서 지워져 표현되지
않는다"가 정확한 설명이다.** 고해상도 지점 조회(음향수심법 원리 자체)로는 열곡의
존재를 확인할 수 있지만, 그 점들을 연속된 3D 곡면으로 "이어 붙이려면" 훨씬 촘촘한
격자(이상적으로는 수 km 이하 간격)가 필요하다는 것을, 이번 재조회 결과가 직접
보여준다.

## 5. 향후 보완하면 좋을 점 (과제연구 심화 방향 제안)

1. 지자기 이상을 더 촘촘한 간격(0.05°~0.1°)으로 조회하거나, 가능하다면 선박 실측 자력계
   측선 자료(NCEI trackline geophysical database)를 직접 받아 축 인근 좁은 줄무늬를 더
   정밀하게 재현 *(위도별 확장(6개 위도)은 이번에 완료했으나, 간격을 더 좁히는 것은 여전히
   남은 과제)*
2. 3D 지형면의 격자 해상도를 0.5°보다 훨씬 촘촘하게(예: 0.05° 이하) 전면적으로 재조회하면,
   3.7절에서 확인한 열곡 요철이 2D 단면이 아니라 3D 곡면 전체에서도 드러날 가능성이 있음 —
   다만 지점별 API 조회 방식의 한계상 이번에는 26°N 한 단면에서만 검증함
3. 음향수심법 계산에서 가정한 평균 음속(1500 m/s) 대신, 실제 수온·염분 프로파일 기반
   음속 보정식(예: Mackenzie 식)을 적용해 봤을 때 왕복시간 추정이 얼마나 달라지는지
   비교해 보면 "왜 실제 음향측심기가 음속 보정을 하는지"를 정량적으로 보여줄 수 있음
